# Snooze Coffee website

Ready for GitHub Pages. No build, installation, or npm commands are needed.

## Publish

1. Create a repository named `Snooze-Coffee` in your `lendezstudio` GitHub account.
2. Extract `Snooze-Coffee-GitHub.zip`. Upload all extracted contents into the repository root. `index.html` must be at the root, alongside `assets`, `menu`, `our-corner`, `visit`, `style.css` and `app.js`. Do not upload the ZIP itself or place the files inside an extra parent folder.
3. Commit the files. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/ (root)**. Save.
4. Once GitHub finishes publishing, open the URL shown in GitHub Pages settings.

## Pages

- Home: `index.html`
- Menu: `menu/index.html`
- Our Corner: `our-corner/index.html`
- Visit: `visit/index.html`

The package includes all images, the favicon, responsive styling, automatic drink animation, and menu filters. Local links work under a GitHub repository path.

## SEO URL

Canonical URLs, social preview URLs, the sitemap and business structured data are configured for `https://lendezstudio.github.io/Snooze-Coffee/`. If you choose a different repository name, GitHub account or custom domain, replace that URL throughout the HTML files, `robots.txt` and `sitemap.xml`.

## Editing

Edit the HTML files for text and pictures, `style.css` for appearance, and `app.js` for animation and menu filtering. Keep the asset filenames and folder structure intact. The footer credit links to https://lendezstudio.com.
